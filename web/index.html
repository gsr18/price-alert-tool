02 / CONFIGURATION

Alert rules

Configure rule conditions with a guided form; advanced users can edit the JSON above.

No rules loaded

Load a rules JSON file or create a rule to configure your analysis.

LEVEL

Cross a price level

Above: previous close at-or-below; current close above.

Below: previous close at-or-above; current close below.

First observation cannot cross. Omitting direction retains Java's either-direction behavior.

MA_CROSS

Moving-average crossover

Requires full short and long windows. A crossover compares successive full-window averages.

Observations are sorted per instrument; calendar gaps do not interrupt the sequence.

Official fields are short/long; legacy shortWindow/longWindow aliases work too.

RULE EDITOR

Create alert rule
Compatibility notes and engine limits Admin workspace

Types and directions are case-insensitive. JSON property names are case-sensitive. Conflicting aliases, unsupported properties, duplicate IDs, and incomplete rules are rejected. Level thresholds can be any valid BigDecimal value; CSV closes must be positive. Browser decimal scale is capped at 10,000.

Admin mode is a local interface preference, not authentication or a security boundary.

TRANSPARENCY

Historical signals, not forecasts.

Price Alert Studio is a separate client-side JavaScript implementation of the Java CLI. It uses the same rule definitions and matching alert semantics, but the Java JAR does not run in the browser.

Disclaimer: Historical rule alerts are not price predictions, investment advice, or recommendations.

Files are read, parsed, and evaluated locally. There is no upload API, market-data service, database, analytics, or remote storage.
